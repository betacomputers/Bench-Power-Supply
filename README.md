# Bench-Power-Supply
Desktop power supply built from an old Creality CR-10

## BOM
* 1x Digital Voltmeter & Ammeter
* 1x LTC3780 Buck Converter
* 1x 200kΩ Potentiometer
* 1x 500kΩ Potentiometer
* 2x Banana Binding Post
* 3D Printed Housing

#### CR-10 Parts (most older 3d printers will have)
* 1x P360W12V Power Supply
* 1x Switch
* 1x Female AC Plug
* 18 Gauge Wire
